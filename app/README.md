# AI Chatbot Application

This application features a sleek UI with an AI chatbot powered by the Ollama model. The chatbot behaves similarly to the one implemented in `demo.py`.

## Features
- Sleek and modern user interface
- AI chatbot powered by Ollama
- Local and efficient AI model execution

## Project Structure
- `frontend/`: Contains the UI components
- `backend/`: Handles the chatbot logic and integration with Ollama
- `shared/`: Shared utilities and configurations

## Setup
1. Navigate to the `app` directory.
2. Follow the instructions in the respective `frontend` and `backend` directories to set up the application.
